# 🔐 VaultX — Secure Personal Vault System

VaultX is a cloud-based personal document vault system inspired by DigiLocker and Google Drive. It allows users to securely upload, organize, preview, and manage important documents online using Firebase and Google Drive integration.

---

# 🚀 Features

✅ User Registration & Login
✅ Firebase Authentication
✅ Google Drive API Integration
✅ Cloud Firestore Database
✅ Category-wise Document Storage
✅ Dynamic Dashboard
✅ File Upload & Preview
✅ Delete Documents from Drive & Firestore
✅ User-specific Secure Access
✅ Responsive Modern UI
✅ Google OAuth Integration

---
